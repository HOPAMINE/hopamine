# Fonts

Drop the licensed Hopamine faces here with these exact names (woff2 preferred, ttf/otf also work):

- `Bootzy.woff2` or `Bootzy.ttf` — display (T1)
- `Grotalism-Black.woff2` or `Grotalism-Black.otf` — caps-only alternate
- `Glamour.woff2` or `Glamour.ttf` — cursive overlay

No Google Fonts, by rule. Until these are added, HQ uses system fallbacks.
The repo is private; check the licences allow web embedding before the deploy is shared outside the team.
